# Rime 皮肤外挂器 (Rime Skin Overlay) v2.0

让小狼毫 (Rime/Weasel) 输入时，候选框旁边跟随显示图片。纯外挂思路：不改输入法本体，像油猴脚本一样在旁边挂个透明小窗。

注：纯 openclaw 生成，本人不懂代码纯小白，所以软件还不是很成熟

## ✨ 功能

- 🎯 **跟随候选框**：打字时图片自动出现在候选框右侧（可贴左/中间），垂直居中
- 🙈 **自动隐藏**：不打字 / 切到其他输入法时，图片自动消失，不挡任何东西
- 📚 **图层选项**：图片可置于候选框【上方】盖住它 / 【下方】被它压住（下方仅重叠居中时生效，需候选框为置顶窗口）
- 🖼️ **图形化配置向导**：选图 → 实时预览（候选框+图片组合样式）→ 微调 → 保存，所见即所得
- 🎛️ **显示期特效**：**水平翻转**（通用区 ③ 那一行、**统一管所有图层**）/ 圆角（0-120px）/ **点阵羽化**（0-80px 带宽，用 4×4 有序抖动近似半透明渐隐）；随手预览，只影响显示、不动图片文件，随皮肤一起存档（透明是硬边，见「已知限制」）
- 🧊 **真·半透明渲染（增强模式）**：向导 **⑩ 点阵羽化** 行末勾「**增强（真羽化）**」→ 真 alpha 分层窗，**半透明立绘 / 柔和阴影 / 真渐隐羽化**都能出，透明区域还能**点击穿透**；默认「兼容」与 1.6 逐像素一致，随时取消勾选切回
- ✨ **⑩ 旁「增强（真羽化）」开关**：不用去翻设置项 —— 直接勾 ⑩ 点阵羽化 行末这个开关就是切「增强」（它就是渲染模式唯一的入口，原来那个「⑪ 渲染模式」单选已在第三轮删掉）；勾上后点阵羽化的勾选会置灰（它是**兼容模式下的近似**），**预览区是纯色底**，当场能看出「硬边 vs 平滑过渡」的差别
- 🧩 **套层皮肤（多图层）**：一个皮肤可叠多张图（向导 **⑫ 图层**：加 / 删 / 上移 / 下移 + 「随宽度比例」）；**选中哪一层，上方的 ④⑤⑥ 滑条就是调那一层**的大小与位置，每层参数各自记住、来回切层不串；**③ 贴边方向与水平翻转都在通用区、一处改全部图层**（预览实时合成，默认 1 层 = 老行为）
- 🎨 **一键生成候选框配色**：向导 **「🎨 生成候选框配色…」** 按当前图片（动图取所有帧）自动生成亮 / 暗两套候选框配色注入小狼毫 —— 打字时候选框跟着图片变色，改前自动备份、随时可还原；没生成过就对老用户零影响。**皮肤没存过档案会先提示「先保存皮肤名」**（方案名跟着皮肤名走、切皮肤整套恢复），写进 `weasel.custom.yaml` 的新配色块**带 `# ===== 皮肤名 =====` 分节标题与空行**，不再和上一个皮肤「并在一起」
- 🧹 **清理垃圾**：一键清掉程序目录里的临时/备份文件（走回收站可还原）；skins/、配置、日志、说明文档、正在使用的图片一律不动；**配置指向的冗余副本会自动改指向皮肤后再清**
- 📝 **关键点日志**：`error.log` 带时间戳记关键操作（启动环境指纹/配置保存/切皮肤/候选框命中/异常），超 256KB 自动轮转
- ✂️ **图片预处理**：自动/手动裁剪、纯色背景一键抠图（不用再自己找透明底图）；**动图能在对话框里当场播放预览**（▶ 播放 / ⏸ 暂停 / ⏮ 首帧 / ◀ ▶ 逐帧 + 键盘 ←→ 空格），按需解码不卡 UI，裁剪框对每一帧一致；**多图层时选中的那一层单独处理**（结果只回到该层，不动主图与其它层）；**动图模式下右栏可滚动**，最下方的「应用 / 重置 / 取消」永远可见可点
- 🗂️ **系统托盘**：右下角羽毛图标，左键打开配置程序，右键菜单退出，不用进任务管理器
- 🎨 **多皮肤管理**：皮肤 = 图片 + 全套参数存为独立档案，托盘「皮肤选择」子菜单 / 向导下拉一键整套切换，选中即应用（含正在运行的外挂），随时换肤
- 🧈 **动态抠色键**：自动统计图片颜色，选一个图中不存在的颜色当透明键，**图片含品红也不再被抠穿**
- 🎞️ **动图支持**：GIF / 动图 WebP / APNG 逐帧播放（每帧时长跟源文件，20-1000ms 钳位）；窗口隐藏自动暂停、帧按需解码（LRU 6 帧），200 帧大片也不担心内存；向导里可「▶ 预览动画」
- 🚀 **开机自启**：向导复选框 / 托盘菜单一键开关（登录 Windows 后**静默启动到托盘**，不弹窗不显窗口）
- 🔄 **改图即生效**：运行时直接替换图片文件，2 秒内自动重载，无需重启
- 🛡️ **防重复启动**：已有实例时弹窗提示，不会开多个打架
- 🖱️ **可交互**：拖动微调位置、滚轮缩放、右键菜单、快捷键隐藏

## 🚀 快速开始

1. **准备图片**：任意图片（PNG / JPG / WEBP / GIF / BMP）即可，竖屏壁纸、截图、立绘都能用
2. **双击 `RimeSkinOverlay.exe`** → 首次自动打开配置向导（**上 = 通用区（①~⑦，含预览）/ 下 = ⚙ 高级设置（⑧~⑭，横排多列）**，窗口约 999×913；**点一下 ⚙ 高级设置那行标题就能折叠**，折叠后窗口只要约 590 px 高）：
   - ① 选择图片 → 点「图片预处理」：自动裁剪到角色 / 手动裁剪（可锁定 1:1、2:3、3:4、9:16 比例）/ 纯色背景一键抠图（背景自动变透明）；**动图还能当场 ▶ 播放预览**，逐帧看清楚再裁；**多图层时处理的是当前选中的那一层**（结果只回到该层）
   - ② 候选框类型：单行横排 / 双行横排 / 竖排（可一键「读取当前 Rime 配置」自动识别）
   - ③ 贴边方向（贴左 / 右 / 居中）+ 水平翻转 —— **都在通用区，一处改全部图层**
   - ④⑤⑥ 缩放 / 水平微调 / 垂直微调：选中哪一层，调的就是哪一层（实时预览）
   - ⑦ 预览：透明区是**纯色底**，兼容 = 硬边、增强 = 边缘平滑过渡
   - ⚙ 高级设置（点标题可折叠）：**⑧ 图层**（图片压候选框上方 / 被压住）、**⑨ 特效**（圆角）、**⑩ 点阵羽化**（行末「**增强（真羽化）**」开关就是切增强模式；**原来那个「⑪ 渲染模式」单选第三轮已删**）、**⑫ 图层**（叠多张图：加 / 删 / 上移 / 下移 + 随宽度比例）、**⑬ 皮肤管理**、**⑭ 开机自启**
   - 提示：内容多时仍可**滚动**查看，底部按钮始终固定在窗口下沿，不用担心点不到「保存并启动」
   - ⑬ 里的 **🎨 生成候选框配色**（可选）：按当前图片生成候选框配色并注入小狼毫（改前自动备份，可一键还原）；**皮肤还没存名字时会先提示保存**（配色方案跟着皮肤名走，写进 `weasel.custom.yaml` 带分节标题）
   - ⑭ **开机自启**（可选：登录 Windows 后自动启动）→ 点「保存并启动」
3. **打字** → 图片自动跟随候选框，不打字自动隐藏

## 🧠 原理

小狼毫的候选框是 TSF 框架窗口（类名 `ATL:` 前缀，注入在输入应用进程内）。
程序用 WinEventHook 事件驱动监听窗口显示/移动/销毁，命中候选框后把透明
置顶小窗贴到其左/右侧（候选框重建自动恢复跟随，无候选框自动隐藏）；
候选框识别统一判定：`ATL:` 类名 + TSF 样式（POPUP+TOOLWINDOW+NOACTIVATE）
+ 尺寸，weasel 进程内微缩指示窗（如大小写切换提示）除外。图片窗本体用
`tkinter` + `overrideredirect` + `-transparentcolor` 实现无边框透明置顶。
其中**兼容模式**的图片窗用 `-transparentcolor`，它只能把**某一种纯色**整体抠成透明（二值：抠或不抠），
所以兼容模式的透明边缘本质上是**硬边**——圆角 / 抠图 / 立绘轮廓会有轻微锯齿，也做不出半透明羽化（详见下方「已知限制」）。
**增强模式**（2.0 新增）改用 `WS_EX_LAYERED` + `UpdateLayeredWindow` 直接推 32bpp 预乘位图，
逐像素 alpha 交给系统合成，于是真·半透明、柔和边缘、透明区点击穿透都成立；两种模式共用同一套
定位 / 交互 / 动图代码，只是换「怎么把画面送到窗口上」这一步。

### 配置项说明（config.json）

| 字段 | 含义 |
|---|---|
| `image` | 图片路径 |
| `layout` | 候选框类型：`horizontal_single` / `horizontal_double` / `vertical` |
| `side` | 贴边方向：`left` / `right` / `center` |
| `scale` | 缩放倍率（0.2-2.0） |
| `base_height` | 基准高度（像素，默认 300），最终图片高度 = base_height × scale |
| `offset_x` / `offset_y` | 水平/垂直微调偏移（像素） |
| `flip_h` | 水平翻转（显示期，不改图片文件；动图同样生效） |
| `autostart` | 开机自启意图（真相看启动文件夹里有无 `RimeSkinOverlay.lnk`；快捷方式带 `--tray` → 开机静默到托盘） |
| `corner_enabled` / `corner_radius` | 圆角开关 / 半径（px，按缩放后的显示尺寸） |
| `feather_enabled` / `feather_radius` | 点阵羽化开关 / 带宽（px，0-80） |
| `render_mode` | 渲染模式：`compat`（默认，1.6 的键色抠色路径）/ `alpha`（真 alpha 分层窗）。缺键或写错一律按 `compat` 处理 |
| `schema` / `layers` | 多图层皮肤档案（`schema:2`）。**贴边方向（`anchor`）与水平翻转（`flip`）自 R11/R13 起统一由顶层 `side` / `flip_h` 驱动**：向导里改一次，所有图层跟着变，保存前会统一写盘；每层仍各有自己的微调 / 缩放 / 比例。老档案没有这两个键也能正常读，程序读入时自动升级为单图层 |

## ⚠️ 已知限制

- 运行时透明背景用动态抠色键（默认品红 `#FF00FF`）：**图片含品红时会自动换成其他颜色做键色**，不再需要避讳品红/玫红/亮粉
- 纯色抠图对「背景接近纯色」的图效果好；复杂背景建议先用在线工具抠图后再挂
- **不打字 / 切换到其他输入法时**，图片窗自动隐藏（不挡任何东西）；候选框出现时才跟随显示
- 候选框检测基于 `ATL:` 类名 + 尺寸特征，如遇其他 TSF 输入法误判可提 issue
- 小狼毫本体不支持候选框背景图/动态变色，故本工具采用外挂方案
- 动图建议用**动图 WebP / APNG**（真 alpha）；GIF 是二值透明，边缘可能有锯齿
- 圆角 / 点阵羽化都是**显示期特效**（不改图片文件）
- **⚠️ 透明能力分两档（用之前请知道）**：
  - **兼容模式（默认，与 1.6 完全相同）**：靠 `-transparentcolor` 单色键抠透明，只有「完全透明 / 完全不透明」两档，
    没有半透明羽化能力。带来：圆角、抠图边缘、立绘轮廓有**轻微锯齿**（圆角已用 4× 超采样优化，近看仍可能看出）；
    **点阵羽化**用 4×4 有序抖动把渐变化成点阵（远看像渐隐，贴近看是细点）；透明区是「整块消失」，不存在渐变过渡。
  - **增强模式（向导 ⑩ 点阵羽化 行末的「增强（真羽化）」开关）**：真 alpha 分层窗，逐像素半透明 —— **半透明立绘、柔和阴影、真渐隐羽化**
    都能出，透明区还能**点击穿透**。代价是每帧多一次位图推送（实测约 3ms/帧），老机器跑 30fps 动图若觉得卡可退回兼容。
  - 两种模式**随时切换**：保存后即时生效，正在显示的话重新选图 / 切一次皮肤就会用新模式重绘。
- **⚠️ 第三轮的两处用法变化（多层套层皮肤请照这个改）**：
  - **不要再用「一层贴左、一层贴右」左右夹持**。**③ 贴边方向现在统一管所有图层**，各层不再各存一份贴边方向；
    原先靠左右夹持做的套层效果，改用 **⑤ 水平偏移** 给每层单独挪位置实现（这个取舍已与开发者确认）。
  - **③ 贴边方向与水平翻转都在通用区、统一管所有图层**：改一次，所有图层一起跟着变（预览 / 图层列表文案 / 保存结果一致）。
- **⚠️ 打字时图片闪烁只在增强模式下确认修好**：本轮修的是**增强（alpha 分层窗）**路径的闪烁。如果你用的是**兼容模式**
  且打字也闪，说明还有第二个根因（两条路径机制不同），请把现象反馈给开发者 —— 详见 [CHANGELOG.md](CHANGELOG.md)
  「第四批 R14」与「需真人确认」第 1 条。
- 动图帧数很多（>100）时按需解码：第一帧后能看到画面，滚动/切换瞬间可能有几十 ms 解码延迟
- **动图 + 多图层同时打字**：动画帧仍需每帧重合成整张画布（多图叠加时的必要成本，本版未优化）
- 坏图 / 缺图在极端情况下仍可能崩 —— **v1.6 起就有的老毛病**，非 2.0 引入；遇到请把 `error.log` 发出来
- 多显示器场景：图片窗跟随主候选框所在屏幕（未做多屏位置修正）
- 首次运行 exe 可能触发杀软（360/火绒/Defender）误报，属 PyInstaller 打包常见现象，请允许运行

## ❓ 常见问题

**Q: 双击后没反应/图片不显示？**
- 确认正在使用小狼毫输入法并已打字（候选框出现时才显示）
- 确认候选框类型选对了（单行/双行/竖排），可点「读取当前 Rime 配置」自动识别
- 查看同目录 `error.log`，把最后几行发给开发者

**Q: 换图后没变化？**
- 直接替换图片文件后等 2 秒自动生效；注意替换的是**配置当前指向的那个文件**（向导直接选的图 / 预处理副本 `cfg_image_*.png` / 皮肤副本 `skins/<名称>/image.png`），如果换的是原图而配置指向副本则不会生效

**Q: 如何完全卸载？**
- 向导取消勾选「开机自启」或托盘菜单关闭，即可移除自启；命令行等价：`RimeSkinOverlay.exe --uninstall`
- 然后直接删除整个文件夹即可（绿色软件，无注册表残留）

**Q: 自启后开机弹出了配置窗口 / 想让它安静地蹲在托盘？**
- 本版自启快捷方式带 `--tray`（静默到托盘）；若用的是旧快捷方式，到向导里把「开机自启」重新勾一次（会强制重写快捷方式）即可

**Q: 圆角 / 图片边缘看着有锯齿、发毛？**
- 如果你用的还是**兼容模式**，这是透明机制的天花板，不是设置问题：单色键抠透明（`-transparentcolor`）只有「全透明 / 全不透明」两种状态，做不了半透明过渡
- **最直接的办法：向导 ⑩ 点阵羽化 行末勾上「增强（真羽化）」** —— 边缘变成真 alpha 渐变，锯齿与硬边一起消失

**Q: 增强模式（真羽化）该开还是关？原来那个「⑪ 渲染模式」去哪了？**
- 第三轮起**「⑪ 渲染模式」单选已删** —— 它就是 **⑩ 点阵羽化 行末的「增强（真羽化）」开关**，只有一个入口，不用再两头对着看
- 想要真·半透明（柔和边缘、半透明立绘、阴影发光），或希望透明区别挡鼠标 → **开**（勾上「增强（真羽化）」）
- 老机器 / 只求稳 / 图片本来就是硬边风格 → **关**（默认「兼容」，与 1.6 完全一致）
- 切换后保存即可；正在显示的话重新选一次图或切一次皮肤，立刻按新模式重绘。觉得不合适随时切回来

**Q: 「🎨 生成候选框配色」会改我的小狼毫配置吗？**

- 没点过这个按钮的话程序**一个字段都不会写**（配置里没有 `rime_scheme` 时整条链路静默跳过）

**Q: 出问题了怎么报错给开发者？**
- 直接把程序目录里的 **`error.log`** 发过去：它按时间戳记录了启动环境（版本/系统/DPI/Rime 布局）、每次配置保存、皮肤切换、候选框命中（句柄+类名+尺寸+进程）和异常堆栈——多数问题靠它就能定位

**Q: 程序目录里堆了一堆 `cfg_image_*.png` / 备份文件，能清吗？**
- 向导或托盘菜单里的「🧹 清理垃圾」一键清（进回收站可还原）：只删普通文件，子目录与白名单/源码/文档/正在用的图片都不碰
