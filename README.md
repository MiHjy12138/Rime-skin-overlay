# Rime 皮肤外挂 (Rime Skin Overlay) v1.2

让小狼毫 (Rime/Weasel) 输入时，候选框旁边跟随显示图片。纯外挂思路：不改输入法本体，像油猴脚本一样在旁边挂个透明小窗。

注：纯 openclaw 生成

## ✨ 功能

- 🎯 **跟随候选框**：打字时图片自动出现在候选框右侧（可贴左/中间），垂直居中
- 🙈 **自动隐藏**：不打字 / 切到其他输入法时，图片自动消失，不挡任何东西
- 🖼️ **图形化配置向导**：选图 → 实时预览（候选框+图片组合样式）→ 微调 → 保存，所见即所得
- ✂️ **图片预处理**：自动/手动裁剪、镜像反转、纯色背景一键抠图（不用再自己找透明底图）
- 🗂️ **系统托盘**：右下角羽毛图标，左键打开配置程序，右键菜单退出，不用进任务管理器
- 🔄 **改图即生效**：运行时直接替换图片文件，2 秒内自动重载，无需重启
- 🛡️ **防重复启动**：已有实例时弹窗提示，不会开多个打架
- 🖱️ **可交互**：拖动微调位置、滚轮缩放、右键菜单、快捷键隐藏

## 📦 依赖

- Windows 10/11（64 位）
- 小狼毫 (Weasel) 0.17+（TSF 版）

> ✅ **无需安装 Python**：已打包为免安装 exe，双击即用。

## 🚀 快速开始

1. **准备图片**：任意图片（PNG / JPG / WEBP / GIF / BMP）即可，竖屏壁纸、截图、立绘都能用
2. **双击 `RimeSkinOverlay.exe`** → 首次自动打开配置向导：
   - ① 选择图片 → 点「图片预处理」：自动裁剪到角色 / 手动裁剪（可锁定 1:1、2:3、3:4、9:16 比例）/ 镜像反转 / 纯色背景一键抠图（背景自动变透明）
   - ② 候选框类型：单行横排 / 双行横排 / 竖排（可一键「读取当前 Rime 配置」自动识别）
   - ③ 贴边方向：左 / 右 / 中间
   - ④ 缩放、水平微调、垂直微调（实时预览）
   - ⑤ 保存并启动
3. **打字** → 图片自动跟随候选框，不打字自动隐藏

### 之后每次双击

- 弹选择框：**「是」= 直接启动**（用现有配置）/ **「否」= 重新配置**
- 想换图片：直接替换图片文件即可（2 秒自动生效），或重新配置选新图

## 🧠 原理

小狼毫的候选框是 TSF 框架窗口（类名 `ATL:` 前缀）。程序用 Win32 API 每 50ms 枚举可见窗口，找到候选框后把透明置顶小窗贴到其左/右侧；无候选框时自动隐藏。图片窗本体用 `tkinter` + `overrideredirect` + `-transparentcolor` 实现无边框透明置顶。

### 配置项说明（config.json）

| 字段 | 含义 |
|---|---|
| `image` | 图片路径 |
| `layout` | 候选框类型：`horizontal_single` / `horizontal_double` / `vertical` |
| `side` | 贴边方向：`left` / `right` / `center` |
| `scale` | 缩放倍率（0.2~2.0） |
| `base_height` | 基准高度（像素，默认 300），最终图片高度 = base_height × scale |
| `offset_x` / `offset_y` | 水平/垂直微调偏移（像素） |

## ⚠️ 已知限制

- 运行时透明背景用品红抠色（`#FF00FF`）：**图片中品红/玫红/亮粉色像素会被当成透明背景抠掉**，建议避免使用这些颜色（图片预处理已支持把背景真正抠成透明，不受此限制）
- 纯色抠图对「背景接近纯色」的图效果好；复杂背景建议先用在线工具抠图后再挂
- **不打字 / 切换到其他输入法时**，图片窗自动隐藏（不挡任何东西）；候选框出现时才跟随显示
- 候选框检测基于 `ATL:` 类名 + 尺寸特征，如遇其他 TSF 输入法误判可提 issue
- 小狼毫本体不支持候选框背景图/动态变色，故本工具采用外挂方案
- 多显示器场景：图片窗跟随主候选框所在屏幕（未做多屏位置修正）
- 首次运行 exe 可能触发杀软（360/火绒/Defender）误报，属 PyInstaller 打包常见现象，请允许运行

## ❓ 常见问题

**Q: 双击后没反应/图片不显示？**
- 确认正在使用小狼毫输入法并已打字（候选框出现时才显示）
- 确认候选框类型选对了（单行/双行/竖排），可点「读取当前 Rime 配置」自动识别
- 查看同目录 `error.log`，把最后几行发给开发者

**Q: 换图后没变化？**
- 直接替换图片文件后等 2 秒自动生效；如果用的是向导选的原路径，需在向导里重新选择

**Q: 如何完全卸载？**
- 先运行 `RimeSkinOverlay.exe --uninstall` 移除开机自启
- 然后直接删除整个文件夹即可（绿色软件，无注册表残留）

**Q: 配置存在哪里？**
- `config.json`（exe 同目录），备份/迁移时整个文件夹一起拷走即可
